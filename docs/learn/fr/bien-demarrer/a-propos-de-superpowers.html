    A propos de Superpowers

    Superpowers est un environnement de développement HTML5 pour faire des jeux 2D et 3D.
    Il peut être étendu avec des plugins et vous pouvez l'utiliser en collaboration temps réel.

    Regardez la vidéo de présentation sur YouTube

    Superpowers est en développement depuis plus d'un an. C'est déjà un très bon environnement de développement mais il est encore en constante évolution.

    Nous avons décidé de le rendre gratuit et open source. Si vous appréciez notre travail, vous pouvez nous soutenir sur patreon.com/SparklinLabs.

    La documentation complète et toujours à jour est disponible en anglais. La version française est maintenue par la communauté. On le passera sur GitHub d'ici peu.
