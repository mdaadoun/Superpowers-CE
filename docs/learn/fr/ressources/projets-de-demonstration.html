    Projets de démonstration

    Vous trouverez les instructions pour récupérer chaque projet sur leur page. Il suffit généralement de cliquer sur Télécharger le ZIP et de le décompresser dans votre dossier projects, puis de redémarrer votre serveur.

    Jeux et démos Open Source

    Vous trouverez toutes sortes de jeux et démos sur GitHub. They will help you learn various aspects of the software.

    Vous pouvez y jouer dans la collection Jeux Open Source faits avec Superpowers sur itch.io.
