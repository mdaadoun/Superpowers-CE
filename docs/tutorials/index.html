📁 Monorepo Directory Organization

All projects, raw assets and markdown sources are structured in the repository:

  • demos/projects/ — Ready-to-run Superpowers projects for each game (Super Pong, Super OXO, Super Sokoban, Super Asteroids, Super Pacman).
  • demos/sources/ — Raw assets (spritesheets, audio files, textures, fonts).
  • demos/tutorials/ — Markdown tutorial sources.
  • docs/tutorials/ — This static handbook website deployed on GitHub Pages.
