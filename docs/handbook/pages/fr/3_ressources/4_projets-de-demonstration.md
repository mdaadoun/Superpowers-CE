# Projets de démonstration

Vous trouverez les instructions pour récupérer chaque projet sur leur page.
Il suffit généralement de cliquer sur `Télécharger le ZIP`
et de le décompresser dans [votre dossier `projects`](/fr/bien-demarrer/installer-superpowers),
puis de redémarrer votre serveur.

## Jeux et démos Open Source

Vous trouverez des tutoriels détaillés pas-à-pas dans notre [Manuel des Démos et Tutoriels](../../tutorials/index.html).
Les projets complets prêts à l'emploi et les ressources graphiques/sonores sont également fournis directement dans le dossier `demos/` du dépôt Superpowers CE !

Vous trouverez toutes sortes d'autres jeux et démos communautaires [sur GitHub](https://github.com/superpowers-extra).
Ils vous aideront à apprendre divers aspects du logiciel.

Vous pouvez y jouer dans la collection [Jeux Open Source faits avec Superpowers](http://itch.io/c/38089/open-source-games-made-with-superpowers) sur itch.io.
